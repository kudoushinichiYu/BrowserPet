## 实机验收

2026-10-29，使用公开测试页面完成以下验收；没有关闭工作页面。起初因 Mac 锁屏暂停实机操作，用户解锁后继续完成。

- Chrome：同标题不同网址的两张页面自动收纳、归档关闭、读回真实链接恢复；重复恢复跳过。
- Safari：重载已有临时助手后关闭/恢复成功，未增加权限，无痕访问仍关闭，原起始页保留。
- 跨应用重启：从本机档案恢复 3 个唯一测试链接，跳过 2 条重复记录、失败 0；实际验证 Chrome 新普通窗口路径，自动收纳未继续新增档案副本。
- 搜索：实体键盘唤出后，英文错拼命中 GitHub、中文首字母命中项目标题；追加无关词后结果为零，三个同标题测试页在 Chrome/Safari 中分别保留。
- 桌宠：收起搜索后两次间隔截图的 PNG 字节完全一致，确认空闲静止；本轮没有新增拖动方向实机验收。

实机发现并修复：恢复仅凭构造对象提前报成功、进行中提示残留旧结果、自动收纳跨新窗口产生副本、完成操作后部分复选框仍禁用，以及项目规则显示前未提交旧编辑状态。修复附回归检查。

本地 `output/validation/` 保留测试截图与报告，不随公开源码发布。验收结束后清理了测试页，临时项目私有备份并还原到原先空项目状态，没有替用户开启持续记录。

## 安装包校验

每次 `scripts/package-dmg.sh` 构建无预置密钥的分发应用，并检查：

- 版本、构建号、arm64 架构、macOS 13 最低系统、严格代码签名。
- 图标、原图集、Chrome 读取/切换/关闭/恢复脚本、Chrome/Safari 助手与源码一致。
- 包中无个人路径、当前本机 Safari 配对密钥或用户工作集文件。
- DMG 校验、只读挂载、安装说明、Applications 链接和自定义卷图标；输出 SHA-256 文件。

## 验证边界

Edge 已实现且通过脚本检查，当前本机已发现安装，本轮未做 Edge 实机验收；Firefox 未接入。跨 Space/全屏全部组合、额外真实 Safari Profile、真实注销/登录周期、另一台干净 Mac 的下载隔离与首次安装仍未完整验收。

当前为 ad-hoc 签名，没有 Developer ID 或 Apple 公证。Safari 临时助手仍有退出/24 小时重载限制。工作集恢复仅打开链接，不能恢复正文、表单或登录状态，也不保证失效原窗口的 Chrome/Edge Profile。

历史版本：0.3.2 完成基础 99 项/组及 Chrome/Safari 运行检查；0.3.3 新增应用和 DMG 图标，未修改浏览器/搜索运行代码。历史本地证据保留在 `output/`。
