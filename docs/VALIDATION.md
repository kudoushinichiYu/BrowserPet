# 验证范围

0.3.3 仅更新应用图标和打包：检查 16–1024 像素的十种 ICNS 表示、原生绘制在明暗背景下的大小图标预览、应用图标注册、DMG 自定义卷图标与原文件一致性、只读挂载、签名和配对密钥排除。下列 99 项/组为 0.3.2 功能检查记录，0.3.3 未修改浏览器与搜索运行代码。

自动检查使用合成页面和隔离临时目录，不读真实浏览记录、不安装扩展，也不修改用户已有浏览器注册。

| 检查 | 覆盖 |
|---|---|
| CoreChecks | 30 项：匹配、排序、2000 条页面性能、用途/原组/网站/窗口分组、会话与过期 |
| SearchRefreshChecks | 4 项离屏 AppKit：多次乱序同内容不重建、元数据更新不重绘、单行更新、插入后滚动锚点 |
| chrome-scripts | 9 项：多窗口、隐私优先过滤、权限错误、原 ID 切换、最小化恢复、失效目标拒绝 |
| group-extension | 7 项：原组属性、无痕排除、最小权限、固定扩展来源 |
| safari-extension | 8 项：普通窗口确认、Safari 隐私字段兼容、精确切换、旧实例拒绝、权限、Edge 脚本路由 |
| MultiBrowserChecks | 26 项：来源失败隔离、Safari 会话/Profile、真实回环 HTTP 配对/CORS、每用户密钥、旧配对迁移、文件权限、带空格安装路径、注册冲突保护 |
| PetAtlasChecks | 10 组：所有 69 帧边界、独立主体与透明画布，输出合成预览 |
| BridgeChecks | 5 项：真实 Unix socket 的消息帧、非法长度与原组同步 |

共 99 项/组检查。镜像检查另含：DMG 校验和、只读挂载、严格签名验证、arm64 架构和最低系统、资源一致性、安装说明与 Applications 链接、发布包不含本机配对密钥或用户路径。

已有本机验收：Chrome 搜索/原页切换与实体快捷键；Safari 真实页面索引、同标题页面区分、按原窗口 ID 切回、最小化窗口恢复、关闭测试页后的索引移除。0.3.2 刷新修复曾观察真实 32 页面/5 分组，后台轮询未插入提示行，列表标识保持稳定。最新分发初始化改动使用隔离目录自动检查，未在另一台干净 Mac 做安装验收。

当前未声明通过：Edge 实机（未安装）、跨 Space/全屏全部组合、额外真实 Safari Profile、真实注销/登录周期、其他 Mac 的下载隔离与首次安装。Developer ID 签名和 Apple 公证尚未完成。不得以脚本检查代替这些实机验收。

本地 `output/` 保留开发验收证据，不随公开源码或安装包发布，避免包含个人页面与路径。
