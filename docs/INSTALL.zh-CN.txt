BrowserPet 0.4.0 — Mac 桌宠找页与项目收纳工具

系统要求：Apple Silicon（arm64），macOS 13 或更高；Safari 接入要求 Safari 18.4 或更高。
此个人测试版采用 ad-hoc 签名，未使用 Developer ID 签名、未经 Apple 公证。
首次下载后 macOS 可能阻止启动，或需要你在系统设置中审查打开许可。
若组织策略不允许，使用源码自行构建；请勿关闭系统安全防护。

安装/升级：退出旧版，将 BrowserPet.app 拖到 Applications，再从“应用程序”打开。
使用：点击小猫，或按 Control + Option + Space。上下选择，Enter 切换，Esc 收起。
搜索支持拼音、首字母和英文错拼；精确匹配优先，多词需全部命中。
小猫空闲静止。右键可隐藏、设置或退出；隐藏后菜单栏爪印和快捷键仍可用。

项目工作集：搜索框右侧收纳图标或小猫右键 → 项目工作集与清理。
创建项目后可保存所选链接、按关键词自动收纳、归档并关闭所选、按需一键恢复。
清理默认 3 天未观测使用，也可按与当前项目是否相关筛选；先预览，再由你选择关闭。
归档必须先保存成功才会关页；恢复跳过同一浏览器已打开的相同链接，原记录仍保留。
仅保存标题、网址、原分组和使用时间，不保存正文、表单、滚动位置或登录状态。
原窗口失效时新建普通窗口，Chrome/Edge 不保证原配置文件，不自动重建浏览器原组。
使用时间从创建项目后观察起累计，不读取此前历史；应用未运行时的使用不可见。
项目资料仅保存在本机 Library/Application Support/BrowserPet/Workspaces。

Chrome / Edge：运行浏览器后，按 macOS 提示授予自动化权限。
基础搜索、切换不需要扩展。Chrome/Safari 工作集已实机验收，Edge 当前未做实机验收。
Chrome 原有分组：在面板点击“连接原分组”，注册本机连接并打开助手文件夹；
在 Chrome 扩展页开启开发者模式并“加载已解压的扩展”。每个 Profile 分别加载。
应用移动后需重新注册；建议先安装到“应用程序”再连接。

Safari：在面板点击“Safari 连接”，生成并打开本用户的 SafariHelper 文件夹。
在 Safari 设置的开发者选项中“添加临时扩展”，选择该文件夹，按系统提示授予网站访问权限。
从旧版升级需重新生成并重载 0.4.0 助手，才能使用工作集关闭/恢复；权限不增加。
不要开启隐私浏览访问。临时扩展在退出 Safari 或 24 小时后需重新加载。
密钥与助手配置仅在本机生成；不要分享 Library/Application Support/BrowserPet 文件夹。

搜索索引在内存；启用项目后，项目链接资料与使用时间在本机落盘。
无痕默认排除，不读正文、历史或书签，不向外网上传数据；恢复导航会由浏览器正常请求网页。
完整说明与源码：https://github.com/kudoushinichiYu/BrowserPet
