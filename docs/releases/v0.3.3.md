### 安装与安全提示

下载 `BrowserPet-0.3.3-macOS-arm64.dmg`。适用 Apple Silicon、macOS 13+；Safari 助手要求 Safari 18.4+。

**此版本仍采用 ad-hoc 签名，没有 Developer ID 证书、未经 Apple 公证，因此 macOS 仍可能显示无法验证开发者/恶意软件的提示。新增图标不改变这一状态。** 正式解决此类分发提示需要 Developer ID 签名及 Apple 公证；不要关闭系统安全防护。

浏览器自动化权限属于功能授权，正式签名后仍需由用户授予。Safari 仍采用临时助手，退出 Safari 或 24 小时后需要重载。Edge 尚未实机验收，Firefox 尚未接入。
