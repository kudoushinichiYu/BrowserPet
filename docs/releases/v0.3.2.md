BrowserPet 首个公开 macOS 安装包：从桌宠入口统一搜索已打开页面，按原 ID 切回原标签页。

- Chrome 多窗口与多 Profile 搜索；连接只读助手后保留原组名、颜色和初始折叠状态。
- Safari 配套临时助手；Edge 基础搜索与切换已实现。
- 原组优先，未分组按用途归类，也可按网站或窗口查看。
- 紧凑单行结果、标题省略与悬停滚动，默认快捷键 Control + Option + Space。
- 修复后台刷新导致列表周期性闪动；相同内容不重建，变更行局部更新，保留选择与滚动位置。
- 原创小猫 7 种动画与 16 方位注视，修复运动帧带入相邻碎片，支持拖动、隐藏和减动模式。
- 分发版首次运行生成每用户 Safari 配对密钥，安装包不含开发者的配对配置；Chrome 本机连接按实际安装路径注册。

### 安装

下载 `BrowserPet-0.3.2-macOS-arm64.dmg`，将应用拖到 Applications 后打开。适用 Apple Silicon、macOS 13+；Safari 接入要求 Safari 18.4+。安装包不需要 Xcode、Python 或 Node。

**当前为 ad-hoc 签名的个人测试版，未使用 Developer ID、未经 Apple 公证。macOS 可能阻止首次启动或要求在系统设置审查许可。** 若组织策略不允许，请从源码构建，不要关闭系统安全防护。

Chrome/Edge 需系统自动化授权。Chrome 原组需加载配套扩展；Safari 需点击面板“Safari 连接”生成并手动加载临时助手、授予网站访问。Safari 临时助手在退出浏览器或 24 小时后需重载，隐私浏览保持禁用。应用移动后需重新注册 Chrome 连接。

### 验证与限制

99 项/组自动检查覆盖匹配、增量刷新、协议、隐私过滤、真实回环/Unix socket、每用户初始化及全部 69 动画帧；DMG 另经校验、只读挂载、严格签名及无个人密钥检查。

Chrome 与 Safari 有本机运行验收。Edge 尚未安装做实机验收；跨 Space/全屏全部组合、额外真实 Safari Profile、登录周期及其他干净 Mac 安装尚未验证。Firefox 未接入，Edge 原标签组暂不支持。

页面数据仅在本机内存处理，无痕默认排除，不读取正文、书签或历史，不向外网发送。安装包附 SHA-256 校验文件。
