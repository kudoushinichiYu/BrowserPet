BrowserPet v0.4.0 将临时打开的网页收纳为可恢复的项目工作集，同时加入模糊搜索和空闲静止。

- **项目工作集**：保存标题、网址、来源和原分组，按项目关键词自动收纳；本机保留使用时间。
- **归档清理与恢复**：默认预览 3 天未观测使用的页面，也可筛选与当前项目无关的页面。整批保存成功后才关闭所选；一键恢复链接、跳过已打开项，保留归档记录。
- **模糊搜索**：支持中文拼音/首字母、英文词首字母、顺序缩写及少量英文错拼，精确匹配优先，多词仍需全部命中。
- **安静桌宠**：空闲时静止并停用动画计时器；悬停与等待/错误反馈只播放一轮，拖动和实际操作时保留动画。
- **可靠性修复**：恢复成功需读回真实窗口、标签 ID 和网址；自动收纳复用恢复后的链接；修正进行中提示、操作后复选框状态及项目规则显示。

### 安装与升级

下载 `BrowserPet-0.4.0-macOS-arm64.dmg`，退出旧版，将应用拖入 Applications 后打开。需要 Apple Silicon、macOS 13+；Safari 助手要求 Safari 18.4+。

**Safari 用户需点击“Safari 连接”重新生成并重载 0.4.0 助手，才能使用工作集关闭/恢复，权限不增加。** 隐私浏览保持关闭。临时助手在退出 Safari 或 24 小时后仍需重载。

当前仍为 **ad-hoc 签名、未使用 Developer ID、未经 Apple 公证** 的个人测试版，macOS 可能提示无法验证开发者或安全性。请勿关闭系统安全防护。

### 数据与恢复边界

创建项目后，链接资料和观察时间只在本机保存；不读取此前浏览历史，也不上传数据。只保存链接元数据，**不保存离线正文、表单、滚动位置或登录状态**。原窗口失效时创建普通新窗口，Chrome/Edge 不保证原 Profile；原分组仅作为保存资料，不自动重建浏览器标签组。

### 验证

164 项/组自动检查通过。Chrome/Safari 已实机验证自动收纳、归档关闭、真实链接恢复、重复恢复跳过，以及退出重开 BrowserPet 后的恢复；英文错拼、中文首字母和空闲静止也已实机确认。DMG 另验证镜像、只读挂载、签名、图标、架构与资源，以及个人密钥/工作集未打入包，附 SHA-256 校验文件。
